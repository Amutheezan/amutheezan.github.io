### Formal Methods

Formal methods are use to prove the model and identify the loop holes in the model implementation.

### Murphi3.1

Murphi3.1 is a tool, which can verify a system model and verify the validity of the model.

### Basic Tutorials
#### Setting Constants
We can set simple constants using following 
syntax,
```
const
  <constant_name>: <const_value>;
```

#### Defining Variables

Variable can be defined in the following format

Simple definition,
```c
var
	<variable_name>: <type>;
```
Using array definition,
```c
var
	<variable_name>: array[...] of <object>;
```
#### Defining Types

Types can be defined in the following format

Simple Definition:

```c
type
  	<type_name>: scalarset(<integer_value>);
```

Complex Structure:

```c
type
	<type_name>: record
		<attribute_1>: enum { 
			ENUM_VAL_1,
			ENUM_VAL_2
		};
		<attribute_2>: <type_name>;
	end;
```
In complex structure, we can combine on or more simple types and complex ones as well. Also we can provides enumerations as attributes. Types can be resembles the object of the general programming.
