% ─── Overview ────────────────────────────────────────────────────────────────
\section{Overview}

This repository contains the source code for
\href{https://amutheezan.com}{\texttt{amutheezan.com}}, the personal academic
portfolio of Amutheezan Sivagnanam --- Postdoctoral Fellow at the University of
Houston with research focus on AI for Transportation Optimization and
Reinforcement Learning.

The site is a static website generated by \textbf{Jekyll} and hosted on
\textbf{GitHub Pages} with a custom domain.

% ─── Technology Stack ────────────────────────────────────────────────────────
\section{Technology Stack}

\begin{itemize}[leftmargin=1.5em, itemsep=2pt]
    \item \textbf{Static site generator:} Jekyll (via the \texttt{github-pages} gem)
    \item \textbf{Theme:} Minimal Mistakes v3.4.2, vendored in-repo
    \item \textbf{Templating:} Liquid
    \item \textbf{Stylesheets:} SCSS (compiled by Jekyll)
    \item \textbf{JavaScript:} jQuery + plugins, minified via \texttt{uglify-js}
    \item \textbf{Hosting:} GitHub Pages with custom domain (\texttt{amutheezan.com})
    \item \textbf{Comments:} Staticman (configured but inactive)
\end{itemize}

% ─── Local Development ───────────────────────────────────────────────────────
\section{Local Development}

\subsection*{Prerequisites}

\begin{itemize}[leftmargin=1.5em, itemsep=2pt]
    \item Ruby + Bundler
    \item Node.js + npm
\end{itemize}

\subsection*{Setup}

\begin{lstlisting}[language=bash]
bundle install    # Install Jekyll and Ruby gems
npm install       # Install JS build tools (uglify-js, onchange)
\end{lstlisting}

\subsection*{Running the Dev Server}

\begin{lstlisting}[language=bash]
# Standard (uses production config)
bundle exec jekyll serve

# With development overrides (local URL, no analytics, expanded SASS)
bundle exec jekyll serve --config _config.yml,_config.dev.yml

# With live reload (hawkins gem)
bundle exec hawkins --config _config.yml,_config.dev.yml
\end{lstlisting}

Site is available at \texttt{http://localhost:4000}.

\subsection*{JavaScript Build}

Only needed when editing JS source files in \texttt{assets/js/plugins/} or
\texttt{assets/js/\_main.js}:

\begin{lstlisting}[language=bash]
npm run build:js    # Minify all JS into assets/js/main.min.js
npm run watch:js    # Auto-rebuild on changes
\end{lstlisting}

\textbf{Important:} Never edit \texttt{assets/js/main.min.js} directly --- it is
auto-generated by the build script.

% ─── Common Tasks ────────────────────────────────────────────────────────────
\section{Common Tasks}

\begin{description}[leftmargin=0pt, itemsep=4pt]
    \item[Add a publication]
        Create \texttt{\_publications/YYYY-MM-DD-slug.md}, optionally add PDFs to
        \texttt{files/}, and update \texttt{\_pages/cv.md}.

    \item[Add a talk]
        Create \texttt{\_talks/YYYY-MM-DD-slug.md} and add slides/posters to
        \texttt{files/Presentations/} and \texttt{files/Posters/}.

    \item[Update the CV]
        Edit \texttt{\_pages/cv.md} directly (plain Markdown, no special data source).

    \item[Update author bio / social links]
        Edit \texttt{\_data/authors.yml}. Fields include \texttt{name},
        \texttt{bio}, \texttt{location}, \texttt{email}, and social handles.

    \item[Update navigation]
        Edit \texttt{\_data/navigation.yml} (the \texttt{main} key controls the
        top navigation bar).

    \item[Update downloadable files]
        Replace files directly in the \texttt{files/} directory.
\end{description}

% ─── Deployment ──────────────────────────────────────────────────────────────
\section{Deployment}

\begin{itemize}[leftmargin=1.5em, itemsep=2pt]
    \item \textbf{Automatic:} Push to \texttt{master} $\rightarrow$ GitHub Pages
          rebuilds and publishes.
    \item \textbf{Custom domain:} Controlled by the \texttt{CNAME} file
          (\texttt{amutheezan.com}). Do not delete or modify this file.
    \item \textbf{No CI pipeline} --- GitHub Pages handles the build.
\end{itemize}

% ─── What NOT To Do ──────────────────────────────────────────────────────────
\section{What NOT To Do}

\begin{itemize}[leftmargin=1.5em, itemsep=2pt]
    \item Do \textbf{not} edit \texttt{assets/js/main.min.js} directly.
    \item Do \textbf{not} delete \texttt{CNAME}.
    \item Do \textbf{not} modify files in \texttt{\_sass/vendor/}.
    \item Do \textbf{not} add YAML frontmatter (\texttt{---}) to files in
          \texttt{assets/}.
    \item Avoid inline JS \texttt{//} comments inside \texttt{<script>} tags in
          layouts (HTML compression removes newlines and breaks them).
\end{itemize}
